# Fonts

Choose the primary font family used across your website frontend.

## Selecting a Font

Go to **Appearance → Fonts**. You'll see a grid of available fonts, each with a live preview.

| Font | Style |
|------|-------|
| Inter | Sans-serif (default) |
| Roboto | Sans-serif |
| Open Sans | Sans-serif |
| Montserrat | Sans-serif |
| Playfair Display | Serif |

1. Click on a font card to select it.
2. Click **Save Font Settings** to apply.

The selected font is applied globally to all frontend pages. The change takes effect immediately — no theme rebuild required.

::: tip
The font preview shows sample text so you can compare typefaces before committing. Inter is the default and works well for most use cases.
:::
