# Appearance

The Appearance section controls how your site looks: themes, navigation menus, and typography. Everything is managed from the admin panel with no code required: activate a theme, edit its templates visually, arrange menu items by drag-and-drop, and pick the fonts that define your brand.

## What You Can Do

- **🎨 Themes**: Activate, configure, and edit theme templates directly from the admin panel.
- **🧭 Menus**: Build navigation menus for your site.
- **🔤 Fonts**: Manage the typography used across your site.
