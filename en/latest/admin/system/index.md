# System

The System section keeps your Vale installation healthy over time. From here you install signed updates with automatic rollback, take and restore backups, and configure privacy and consent settings for GDPR compliance.

It also houses operational tools you will hopefully rarely need: command-line maintenance commands, spam protection for forms and comments, and troubleshooting guides for when something misbehaves.

## What You Can Do

- **🔄 Updates & Backups**: Update Vale automatically with signature verification and one-click rollback.
- **🔒 GDPR & Privacy**: Configure privacy settings, IP anonymization, and consent.
- **🖥️ CLI Commands**: Run maintenance tasks from the command line.
- **🛠️ Troubleshooting**: Diagnose common issues.
- **🛡️ Spam Prevention**: Protect your forms and comments from spam.
